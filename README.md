# C Mini Projects 🚀

A growing collection of small C programs built to practice and demonstrate
core C programming concepts — from basic syntax to more involved data
structures and algorithms.

Each project lives in its own folder with its own source code and README.

## Projects

| Project | Description | Concepts |
|---|---|---|
| [Calculator](./calculator) | Command-line calculator supporting `+ - * /` | Variables, data types, `switch`, `scanf`, `printf` |

*(More projects will be added here as they're built.)*

## How to Run Any Project

Each project folder contains a single `.c` file. To compile and run:

```bash
cd <project-folder>
gcc -o program program.c
./program
```

(See each project's own README for exact filenames and example usage.)
